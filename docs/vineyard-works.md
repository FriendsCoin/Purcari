# Vineyard Works — presentation

A presentation that turns the final 12-month biodiversity monitoring report
(Every1Counts, Château Purcari) into concrete vineyard works: what to do, why,
on what data it is based, and in which season.

## Files

- **`vineyard-works.html`** — self-contained, interactive slide deck (19 slides).
  Open it in any browser. Trilingual **RU / RO / EN** language switcher (top
  right), light/dark theme toggle, keyboard navigation (← / →), and a print
  layout (Ctrl/Cmd+P) with one slide per page.
- **`Purcari_Vineyard_Works_RU.pdf`** — Russian version (19 pages).
- **`Purcari_Vineyard_Works_RO.pdf`** — Romanian version (19 pages).
- **`Purcari_Vineyard_Works_EN.pdf`** — English version (19 pages).

## Structure

1. Cover
2. Why it matters — verdict + 6 KPIs
3. The evidence — methodology & key findings
4. Existing systems it builds on — weather-based auto-irrigation, UV tractors,
   grass cover, 25 ha organic, biomonitoring network
5. Priority map — the three zone types (core / transition / periphery)
6. Activity map — detections per hotspot, cameras vs sound
7. Action map — where each work happens on the site
8–16. Nine practices — each with rationale (from the data), concrete works,
   season, and expected benefit
17. Seasonal calendar — all works by season
18. Rollout order by priority
19. Takeaway

## Notes on the maps

The estate GPS available in the shared dataset covers only a few points, and
satellite tiles cannot be embedded in the hosted artifact, so the maps are an
accurate schematic (north-up) of the estate layout with a coordinate frame
anchored to the real recorded extent (≈3 km north–south). Provide exact hotspot
coordinates or a field boundary to place them on precise coordinates.

Source: Every1Counts — "Analysis of data collected over 12 months on the
Château Purcari site", final report, 08 July 2026.
